# 天球 · 太阳的四季轨迹

一个交互式三维天球演示：观测者位于天球中心，太阳的周日视运动轨迹随**观测纬度**与**季节**实时重算。

纯 Canvas 2D 手写三维投影，**零运行时依赖**，不加载任何 CDN、不依赖构建工具，双击 `index.html` 即可运行。

## 演示内容

| 控制 | 范围 | 观察到的变化 |
|---|---|---|
| 观测纬度 φ | −90° ~ +90° | 天极高度、轨迹倾角、昼夜长短 |
| 日期 | 1 ~ 365 天（二分二至一键） | 太阳赤纬 −23.44° ~ +23.44°，轨迹圆整体平移 |
| 时刻 | 0 ~ 24 时（可自动播放） | 太阳沿当日轨迹移动 |

内置预设：赤道、北回归线、北京、北极圈、北极点、悉尼。可直接对照观察「同一日不同纬度」与「同纬度不同季节」的差异。

实时读数：赤纬 δ、高度角 h、方位角 A、时角 H、日出、日落、昼长、正午高度，附四季正午太阳高度对比表。图层可分别开关（四季轨迹 / 地平网格 / 天赤道 / 黄道 / 子午圈 / 天轴天极）。

无需安装任何东西，直接用浏览器打开 `index.html`。

```bash
# 然后访问 http://localhost:8000
```

- **拖拽**：旋转相机
- **滚轮**：缩放视距
- **方向键 ←/→**：微调时刻
- **空格**：播放 / 暂停时间

## 算法要点

**太阳赤纬**由黄经求得：

```
δ = asin(sin ε · sin λ)      ε = 23.4393°
```

其中黄经 λ 以二分二至（第 79/172/266/356 天，对应 0°/90°/180°/270°）为控制点做分段线性插值。相比常用的正弦近似 `δ ≈ 23.44°·sin(...)`，这一形式保证**太阳精确落在黄道线上**，四季节点也精确落在二分二至。

**地平坐标变换**采用标准的赤道—地平旋转：

```
sin h = sin φ sin δ + cos φ cos δ cos H
sin A = −cos δ sin H / cos h
```

时角 `H = (t − 12) × 15°`，t 为地方太阳时。

**昼长**由时角半弧求得，极昼/极夜按 `−tan φ · tan δ` 是否越过 ±1 判定。

## 两次实现修正

**太阳曾不在黄道上。** 早期用正弦近似求赤纬，太阳与黄道线偏离约 0.3°，出现视觉矛盾。改用上述球面几何形式后两者严格重合。

**春分与秋分的轨迹没有单独绘制。** 两者赤纬同为 0°，轨迹就是天赤道本身，重复绘制只会互相掩盖。故由天赤道承担该语义，图例标注为「天赤道 ＝ 春分·秋分轨迹」——这本身也是演示需要传达的几何事实。

## 已知取舍

- 采用**地方太阳时**（真太阳时），中天恒为 12:00，未计入均时差与经度修正。
- 日出日落按**几何地平 h = 0** 计算，未计入大气折射（约 0.57°）与太阳视半径，故昼长比实况偏短 5–8 分钟。这是为保持「太阳轨迹与地平圈交点」在几何上严格自洽的刻意选择，而非计算误差。

## 数值验证

天文计算另用独立脚本做过断言检验，覆盖：赤道春分正午太阳过天顶（h = 90.0000°）、北京夏至正午高度 73.54°、春分日出方位 90.00°（正东）、轨迹各点到天极角距恒为 66.56°、南北半球昼长严格互补至 24.0000 h、相邻纬度轨迹无跳变。
